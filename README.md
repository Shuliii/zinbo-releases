# Zinbo downloads

This repository only holds the Windows installers for **Zinbo**: all your chats in one light window.

**Download the latest version:** [Zinbo-setup.exe](https://github.com/Shuliii/zinbo-releases/releases/latest/download/Zinbo-setup.exe)

Windows 10 and 11 (64-bit). During the beta, Windows may say *"Windows protected your PC"* because Zinbo isn't signed yet: click **More info → Run anyway**.

All versions are listed under [Releases](https://github.com/Shuliii/zinbo-releases/releases).
